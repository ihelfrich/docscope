      What this is

      DocScope extracts clean, correctly-ordered text from documents and re-exports it as TXT, Markdown, RTF, or a text-searchable PDF. Every step runs in your browser through WebAssembly. No file is ever uploaded, which is why it is fast, free, and private by construction.

      How each format is handled

      • PDF — reads the embedded text layer first (instant, perfect fidelity). Pages with no text layer fall back to OCR automatically.
      • DOCX — structural conversion via Mammoth, with real Markdown output (headings, lists, links preserved).
      • EPUB — unpacks the archive, walks the spine in reading order, strips markup.
      • RTF — control-word stripping with Unicode escape handling.
      • Images (PNG/JPG/TIFF/…) — Tesseract OCR.
      • MOBI — experimental PalmDoc extraction; for best results convert to EPUB first.

      Honest limits

      In-browser OCR (Tesseract) is strong but not better than commercial cloud OCR for messy scans. The born-digital path (PDF text layer, DOCX, EPUB, RTF) is where DocScope is genuinely best-in-class: instant and lossless. OCR is the fallback, not the headline.
